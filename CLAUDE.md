# OmniCare front-end

Before any UI work, read **`docs/ui-guidelines.md`**. It covers tokens, the "NG-ZORRO first" rule,
the shared primitives, the single appointment-status mapping and the "French only" rule. Angular
conventions are in `AGENTS.md`.

After a change, run `npx ng test --watch=false` and `npx ng build --configuration production`.
